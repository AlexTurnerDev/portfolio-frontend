# Alex Turner — AI Engineer Portfolio

A modern, performance-focused portfolio website showcasing AI engineering, full-stack development, and embedded systems projects. Built with vanilla HTML/CSS/JS for maximum performance — no frameworks, no build tools, just fast-loading static pages.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Clone the repository: `git clone https://github.com/AlexTurnerDev/portfolio-site.git`
2. Navigate to the project directory: `cd portfolio-site`
3. Open `index.html` in a web browser, or use a local development server
4. (Optional) For live reload during development, use VS Code Live Server extension or similar

Instructions for using the software:

1. Browse to the deployed site at `https://alexturner-portfolio.com`
2. Navigate through sections using the sidebar navigation dots or top navbar links
3. Click project cards to open detailed modal views with technical documentation, demos, videos, and source code links
4. Explore featured projects across three layers: AI & Cloud, Software & Pipelines, Hardware & Embedded
5. View certifications and technical skills in the lower sections
6. Contact information and links available in the footer

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Any modern web browser (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+)
* Text editor or IDE (VS Code, Sublime Text, Vim, etc.)
* (Optional) Live server extension for hot-reload during development
* No build tools, package managers, or dependencies required — pure HTML/CSS/JS
